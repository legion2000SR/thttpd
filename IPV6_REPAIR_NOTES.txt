thttpd 2.26-L2K - IPv6 repair notes

Implemented:
- Explicit IPV6_V6ONLY on IPv6 listening sockets, where supported, so IPv4 and IPv6 listeners can bind the same port independently.
- Fail the IPv6 listener cleanly if the v6-only socket option cannot be applied.
- Avoid NULL hostname formatting in getaddrinfo error paths when listening on all interfaces.
- Validate DNS hostname label lengths and leading/trailing hyphens, in addition to the earlier IPv6 literal and Host header checks.
- Restored the missing config.h from the original source distribution to make the integrated tree buildable.
