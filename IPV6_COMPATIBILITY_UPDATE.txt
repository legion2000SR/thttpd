thttpd 2.26-L2K - Additional IPv6 compatibility work

Changes:
- Accept bracketed IPv6 literals in the -h listening-host option by removing brackets before getaddrinfo().
- Preserve the original hostname for diagnostics and release temporary resolver memory.
- Avoid passing a NULL hostname to sockaddr-size error logging when listening on all interfaces.

Verified on Linux in this environment:
- autoreconf -fi, configure, make: PASS after restoring the distribution's config.h (which is not generated by configure).
- IPv6 loopback -h '[::1]': HTTP/1.1 200 OK.
- IPv6 loopback -h '::1': HTTP/1.1 200 OK.
- IPv4 loopback -h '127.0.0.1': HTTP/1.1 200 OK.

Not verified:
- macOS, FreeBSD, OpenBSD, NetBSD, Windows or other platforms.
- Scoped link-local addresses and interface identifiers; external routing, firewall and dual-stack edge cases.
- CGI, access control, virtual-host mappings, reverse proxies and IPv4-mapped addresses under varied deployments.
- Full fuzzing, sanitizer campaigns, long-duration or concurrency testing.

These changes are incremental; do not interpret as universal IPv6 compatibility.
